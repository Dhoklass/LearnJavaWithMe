### How are collections available?
Collections in java are available as classes and Interfaces, 

Following are few commonly used collections in java
    We are going to study about 4 types of collection frameworks here which are: 
        * ArrayList  -> for variable size collection
        * Set        -> for distinct collection
        * Stack      -> A LIFO DataStructure
        * HashMap    -> for storing key-value pairs

Collection class is available in java.util package 
Collection class also provides static methods for sorting, searching etc...
